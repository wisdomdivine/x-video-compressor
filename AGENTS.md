# Workspace Guardrails

These rules apply on every prompt and across all generated code and replies.

## Banned UI and Visual Elements
1. No emojis
2. No em dashes
3. No pipes
4. No hyphens in copy or text formatting
5. No bullet dividers
6. No green dots or status indicator dots
7. No pulses or pulsing animations
8. No border left accents
9. No shadows or box shadows
10. No borders anywhere (remove all borders)
11. No tags
12. No pills or pill badges
13. No gradients. Use solid colors only
14. Do not use any placeholder icons or boxes for the logo

## Typography and Spacing
1. Light fonts only. Do not use bold or heavy weights unless explicitly asked
2. Simple and minimalist design
3. Lots of whitespace so components and elements are never smushed together
4. Add cursor pointer to all clickable buttons, links, and interactive elements
5. Satoshi font

## Tone and Language
1. Everyday layman grammar
2. Clear, simple, direct phrasing
